# Cookie Clicker

A clean, responsive single-page web application featuring a centered interactive cookie and a live click counter.

## Features

- **Interactive Cookie in the Center**: Beautiful SVG chocolate chip cookie centered on the screen.
- **Click Counter**: Displays the total count of cookies baked/clicked in real time with an animated counter pop effect.
- **Visual Feedback**: Floating `+1` animation emerges at the exact position clicked, alongside interactive push/bounce effects.
- **Reset Functionality**: Easy reset button to restart the counter whenever desired.
- **Responsive & Accessible**: Works seamlessly on mobile and desktop screens with keyboard accessibility support.

## Getting Started

No build tools or external dependencies are required.

### Viewing in Browser

You can simply open the `index.html` file in any modern web browser:

```bash
# On Linux
xdg-open index.html

# On macOS
open index.html

# Or start a simple local HTTP server
python3 -m http.server 3000
```

Then visit `http://localhost:3000` in your web browser.
